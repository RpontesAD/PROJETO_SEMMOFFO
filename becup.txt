Com `pack()` isso praticamente **não é possível**. O `pack` foi feito para empilhar widgets, não para distribuí-los em posições específicas.

A melhor solução é usar um **frame intermediário** e o `grid()`.

```python
botoes = ctk.CTkFrame(self, fg_color="transparent")
botoes.pack(fill="x", padx=15, pady=10)

botoes.grid_columnconfigure(0, weight=1)
botoes.grid_columnconfigure(1, weight=1)
botoes.grid_columnconfigure(2, weight=1)

ctk.CTkButton(
    botoes,
    text="Ver Detalhes"
).grid(row=0, column=0, sticky="w")

ctk.CTkButton(
    botoes,
    text="Editar Rotina"
).grid(row=0, column=1)

ctk.CTkButton(
    botoes,
    text="Inativar"
).grid(row=0, column=2, sticky="e")
```

O resultado será algo assim:

```
┌──────────────────────────────────────────────────────────┐
│Ver Detalhes          Editar Rotina             Inativar │
└──────────────────────────────────────────────────────────┘
```

* `sticky="w"` → cola na esquerda (**West**)
* sem `sticky` → fica centralizado
* `sticky="e"` → cola na direita (**East**)

### Outra opção: `place()`

Se você quiser posicionar exatamente onde quiser:

```python
botao1.place(relx=0.0, rely=0.5, anchor="w")
botao2.place(relx=0.5, rely=0.5, anchor="center")
botao3.place(relx=1.0, rely=0.5, anchor="e")
```

Mas, para interfaces responsivas como a do SEMMOFFO, **eu recomendo usar `grid()`**. Ele é a ferramenta certa para esse tipo de alinhamento e continua funcionando mesmo se o card mudar de tamanho.
